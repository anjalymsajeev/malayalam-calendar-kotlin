# Changelog

All notable changes are documented here. The project follows [Semantic Versioning](https://semver.org/);
0.x releases may contain breaking changes.

## [Unreleased]

## [0.1.0-alpha01]: first preview (ready; pending the first Maven Central publication)

Release notes: [docs/release-notes/0.1.0-alpha01.md](docs/release-notes/0.1.0-alpha01.md).

### Changed (Sprint 7: release readiness)
- JVM default methods (`-Xjvm-default=all`) in all modules; `ObservanceProvider` no longer has `DefaultImpls`.
- The constructors of `InvalidMalayalamDateException` and `DateOutOfSupportedRangeException` are now internal.
- API stability policy for 0.x (ADR-0007).

### Added
- `PerformanceTest` with published measurements; release notes; dependency and size analysis.

### Added (Sprint 6: Android SDK and sample app)
- `kollavarsham-android` (AAR, minSdk 21): `MonthGrid` (plain Kotlin) and the `KollavarshamMonthView` Composable; published to Maven Central with the other modules.
- `sample-app`: monthly calendar, date selection, daily details (Malayalam date, nakshatra, tithi, sunrise/sunset, festivals), Malayalam/English, offline (no INTERNET permission).

### Fixed
- The bundled almanac-corrections file is now loaded by absolute path, so minified (R8) Android apps can't break the lookup by renaming packages.

### Added (release engineering)
- Maven Central publishing (Central Portal) for the five JVM modules: signed jars, sources and Dokka javadoc jars, full POMs.
- `release.yml` workflow (tag `v*`), and `RELEASING.md`.

### Added (Sprint 5: festival and observance engine)
- New module `kollavarsham-festivals`: `FestivalRule` (9 rule types), `ReadingTime`, `Occurrence`, `Festival`, `FestivalCalendar`
  (`dateOf`, `candidates`, `festivalsIn`, `easter`), and 25 built-in `KeralaFestivals`.
- Observance sources: `ObservanceProvider`, `RuleBasedObservances`, `DatedObservances` (CSV), and `ObservanceProvider.combine`.
- Festival reference dataset (126 dates, including 5 out-of-sample).

### Fixed
- `Panchangam.day()`: walking spans could return the same span twice after millisecond rounding at a boundary.

### Added (Sprint 4: Panchangam foundation)
- Astronomy: `Moon.position` (abridged ELP-2000/82, Meeus ch. 47), with a generated term table (`tools/elp-gen`).
- New module `kollavarsham-panchangam`: `Panchangam` (nakshatra, tithi, sunrise/sunset, `day()`), `PanchangamLocation`,
  `PanchangamDay`, `Span`, provider interfaces, and the `Nakshatra`, `Tithi` and `Paksha` enums with Malayalam and English names.
- Lunar reference fixtures (2,888 nakshatra and 2,969 tithi boundaries, 2020–2027) generated by `tools/reference-gen/lunar.js`.

### Added (Sprint 3: localisation and developer experience)
- `MalayalamNumerals` and `NumeralSystem` (Malayalam digits ൦–൯).
- `MalayalamTransliterator` (ISO 15919) and `Transliteration` (COMMON, ISO_15919); `displayName(locale, transliteration)`.
- `KollavarshamDateFormatter` (patterns `y M MM MMMM d dd EEEE G 'literal'`), `DateStyle` (SHORT/MEDIUM/LONG/FULL), `MalayalamDate.format(...)`.
- Developer guide (`docs/guide.md`); standalone consumer sample (`samples/jvm-consumer`) run in CI.
- ktlint (in `check`), Dokka multi-module API docs, Maven publication metadata with sources jars.

### Added (Sprint 2: conversion engine)
- `kollavarsham-astronomy`: VSOP87D solar position (426-term truncation), FK5 correction, nutation, aberration;
  Espenak–Meeus ΔT; Lahiri ayanamsa (two conventions); sankranti search; sunrise and sunset.
- Kerala 3/5-of-daytime month-start rule (`AstronomicalBoundarySource`).
- `KollavarshamCalendar.create()`, `create(configuration)`, `LocalDate.toMalayalamDate()`, `MalayalamDate.toLocalDate()`.
- First verified override: Thulam 1197 = 2021-10-17 (cited).
- Reference dataset of 21 cited month starts; borderline-month list (30 months, 1900–2100); invariant tests for every day 1900–2100.

### Decided
- Lahiri convention A (`LahiriTrue`), on evidence (ADR-0002 accepted).

### Added (Sprint 1: core SDK foundation)
- Gradle multi-module build: `kollavarsham-astronomy` (skeleton), `kollavarsham-core`, `kollavarsham-locale`.
- Domain model: `MalayalamMonth`, `MalayalamWeekday`, `MalayalamDate`, `MonthKey`, `MonthBoundary`,
  `BoundarySource`, `GeoLocation`, `CalendarConfiguration`.
- Validation: `DateValidation`, `KollavarshamException`, `InvalidMalayalamDateException`,
  `DateOutOfSupportedRangeException`.
- `KollavarshamCalendar` conversion, validation, month-structure and arithmetic APIs, running on an
  internal month-boundary source. The astronomical source and the public `create()` arrive in Sprint 2.
- Override layer for evidence-backed almanac corrections (ADR-0005).
- Malayalam and English month and weekday names (`displayName`).
- Public API tracking with the binary-compatibility-validator, and CI.

### Sprint 0
- Research, architecture, algorithm and validation documents; ADRs 0001–0006; accuracy spike.
